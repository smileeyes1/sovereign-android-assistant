# سياسة خصوصية حكيم — جسر ChatGPT

## المبدأ
يعمل ChatGPT الرسمي كطبقة المحادثة والاستدلال. الجسر لا يحتاج مفتاح OpenAI API ولا يحاول استخدام جلسة ChatGPT أو ملفات تعريف الارتباط الخاصة بها خارج ChatGPT.

## البيانات
- لكل جهاز موضوع أوامر وموضوع نتائج عشوائيان ومفتاح ربط خاص.
- أوامر الهاتف مشفرة طرفًا لطرف بصيغة HC1/AES-256-GCM.
- نتائج الهاتف مشفرة طرفًا لطرف بصيغة HR1/AES-256-GCM.
- الناقل العام يرى ciphertext فقط، وليس محتوى اللقطات أو الإشعارات أو الأوامر.
- الجسر مصمم بلا قاعدة بيانات للمحتوى وبلا تسجيل للأسرار.
- اعتماد Bearer الخاص بالجهاز سر حساس ويجب عدم مشاركته.

## الصلاحيات
أدوات القراءة: الحالة، شجرة الواجهة، الإشعارات المأذون بها، ولقطة الشاشة عند توفر صلاحية الوصول.
الأفعال التي تغيّر حالة الهاتف، مثل الفتح أو فعل الواجهة، تبقى خلف موافقة Android التي يطبقها حكيم.
لا يوفر الجسر shell أو root أو قناة أوامر عامة.

## ChatGPT
تعالج OpenAI المحادثة وفق حساب المستخدم وإعداداته وسياساتها. النماذج والأدوات المتاحة تعتمد على خطة الحساب والمنطقة والواجهة وقد تتغير.

## الحذف والفصل
يمكن للمستخدم فصل حكيم؛ بعد الفصل لا ينبغي إعادة الاقتران تلقائيًا دون فعل مستخدم جديد.
