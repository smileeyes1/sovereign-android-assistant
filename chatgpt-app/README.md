# Hakim ChatGPT Bridge

هذا المجلد يحول حكيم إلى ذراع تنفيذي لـChatGPT بدل تشغيل نموذج لغوي مقلد داخل تطبيق أندرويد.

## المبدأ
- ChatGPT الرسمي هو طبقة المحادثة والاستدلال، ويستخدم النموذج والأدوات التي يتيحها حساب المستخدم وخطته.
- لا توجد OpenAI API key في الجسر، ولا تُستهلك أرصدة API.
- تطبيق Android يبقى ذراع التنفيذ عبر HakimUnifiedRelay.
- النقل outbound-only من الهاتف عبر ntfy؛ أوامر القراءة فقط: status/ui/notifications/screenshot.
- launch/action يطلبان موافقة Android قبل التنفيذ.
- لا shell، لا root، لا أوامر عامة.

## التشغيل
- Node.js 20+
- npm install
- npm test
- npm run build
- npm start
- خادم MCP: /mcp
- صفحة ربط الهاتف: /pair
- الصحة: /health

## الاعتماد
نسخة الاختبار تستخدم Bearer credential خاصًا بالجهاز تنتجه صفحة /pair. الرمز سرّ وصول ويجب ألا يُنشر أو يُسجل.
للإرسال العام إلى ChatGPT App Directory يجب استبدال الربط اليدوي بتدفق OAuth/Sign in مناسب ومراجع، مع سياسة خصوصية وشروط استخدام.

## حدود المنتج
توفر apps داخل ChatGPT يعتمد على خطة المستخدم والمنطقة والواجهة وسياسات الحساب. لا يضمن هذا المشروع نموذجًا بعينه ولا يتجاوز حدود الخطة.
