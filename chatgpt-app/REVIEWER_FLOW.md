# مسار المراجع

الوضع الإنتاجي لا يسمح Bearer التطويري افتراضيًا.

المسار الطبيعي:
1. OpenAI host يكتشف protected resource metadata.
2. OAuth/CIMD + PKCE يبدأ.
3. صفحة الربط تنشئ pairing credential عشوائيًا.
4. المستخدم يفتح deep link في تطبيق حكيم.
5. الهاتف يؤكد الربط برسالة مشفرة.
6. يصدر authorization code قصير العمر لمرة واحدة.
7. token exchange يصدر access + refresh tokens.
8. MCP tools تصبح مرتبطة بهذا الجهاز فقط.

## نقطة مراجعة لازمة قبل التقديم
المراجع العام لا يجب أن يحتاج جهاز المستخدم الشخصي. يجب توفير reviewer/demo target منفصل وآمن أو flow تجريبي محدود لا يفتح أي جهاز حقيقي. لا تضف مفتاحًا ثابتًا في المستودع ولا تعطّل OAuth لهذا الغرض.
