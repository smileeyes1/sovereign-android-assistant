# حكيم — مصنع السينما الحرّ (نسخة المصدر ٠.٣)

**حالة الإصدار:** مصدر محفوظ في فرع مراجعة؛ ليس إصدار أندرويد مثبتًا ولا عامل توليد واقعي متصلًا بالجهاز.

## المقصد وسلسلة التنفيذ
«ابتكر → صمّم → ولّد/اجمع → حرّك → سجّل الصوت → ركّب → اختبر → اعتمد → أصلح → أكمل → سلّم». 
إذا طلب المستخدم «اصنع لي فيديو»، فالمقصود ملف قابل للتشغيل، وليس خطة فقط. 
لا يُعتمد النجاح إلا مع MP4 مُتحقق منه ومطابقة SHA-256 للملف المسلم والملف المختبر.

## الموجود بالفعل
- `no_credit_factory.py`: مصدر مصنع رسوم تعليمية محلية للأعداد ١–١٠، مع أرقام شرقية وتشكيل عربي ودقة ٩٦٠×٥٤٠، وملف فحص JSON.
- `auto_make.py`: مدخل طلب عربي واحد، ويرفض طلب مسلسل فوتوغرافي واقعي بدل تغيير الهدف صامتًا.
- قاعدة أندرويد في `HakimVideoFactory.kt`: إعلان صادق لقدرات المصدر، وفلترة المزوّدات. `no_credits=true` افتراضيًا؛ لا اختيار في هذا الوضع إلا لمُنفّذ محلي اجتاز فحص القدرة الفعلية وصرح بعدم طلب الأرصدة. لا يسمح باختيار مُزوّد مدفوع بلا موافقة صريحة عند تعطيل هذا الشرط.
- `tests/verify_open_cinema_free_only.py`: حارس انحدار المصدر والقيود، إلى جانب اختبارات المشروع القائمة.

## الحدود الهامة
**ليس التطبيق موصولًا بهذا المحرّك حاليًا**. لم تُدرَج بيئة Python أو FFmpeg في APK، ولم يُختبر تشغيل المحرّك على الهاتف. لا صوت راوٍ في الفيديو التجريبي، والصوت المُضمَّن صامت. لا توليد ممثلين أو فيديو واقعي بالذكاء الاصطناعي.
يلزم لمشاهد واقعية مفتوحة المصدر مثل Wan 2.2 نموذج مُرخّص، وتحقق مستقل من حقوق الأصول، وقدرة GPU مناسبة. لا يُفترض وجود GPU أو حوسبة مجانية مستمرة.
لا تجاوز لحصص الشركات أو شروطها، ولا رسوم أو نشر أو وصول إلى الكاميرا أو تثبيت للهاتف دون السلطة اللازمة.

## إعادة إنتاج الاختبار محليًا
متطلبات: Python 3، Pillow مع RAQM، خط عربي مثل NotoSansArabic، FFmpeg وFFprobe. 
```sh
python cinema/open_source_factory/auto_make.py 'اصنع لي فيديو عن العدد ٧' --output /tmp/number-07.mp4
python tests/verify_open_cinema_free_only.py
ffprobe -v error -show_streams -show_format /tmp/number-07.mp4
sha256sum /tmp/number-07.mp4
```
إذا نقصت RAQM أو الأدوات يتوقف التنفيذ، ولا يدّعي اكتمال الفيديو.
