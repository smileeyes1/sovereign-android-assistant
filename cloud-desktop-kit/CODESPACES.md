# حكيم — كمبيوتر لينكس مجاني مؤقت من متصفح الهاتف

**الإصدار:** ١٫٣ — ١٣ تشرين الأول ٢٠٢٦.

إذا لم يكن لديك حساب Oracle بعد، فهذا مسار **مستقل مؤقت** عبر GitHub Codespaces، ولا يحتاج إلى تشغيل الكمبيوتر الشخصي.

## افتح واجهة الإنشاء

https://codespaces.new/smileeyes1/sovereign-android-assistant/tree/feature/hakim-cloud-desktop-kit-20261013?quickstart=1

اختر إنشاء Codespace بحساب GitHub الشخصي وبجهاز **نواتين** إن أتيح. يفتح **محرر VS Code في المتصفح مع طرفية لينكس**؛ وهو ليس هاتف أندرويد افتراضيًا ولا سطح مكتب XFCE دائمًا. لا تتطلب هذه الخطوة بطاقة دفع عند توفر الرصيد المجاني الشخصي.

## حدود المصروفات والاستخدام

- GitHub Free الشخصي: ١٢٠ ساعة معالجة محسوبة على أساس النوى بالشهر؛ على نواتين تساوي نحو ٦٠ ساعة تشغيل؛ تخزين ١٥ جيجابايت-شهر. راجع الحصص الحالية قبل التشغيل.
- يُوقف Codespaces الخامل آليًا (افتراضيًا بعد ٣٠ دقيقة). التخزين يستهلك من الرصيد ما بقيت المساحة محفوظة.
- **لا تفعّل الإنفاق المدفوع، ولا ترفع حد الإنفاق، ولا تُنشئ أكثر من Codespace بلا حاجة.**
- استخدم صورة التطوير الافتراضية لـGitHub. لم نضع `.devcontainer` مخصصًا، حتى لا تُحتسب صورة حاوية جديدة من حصة التخزين؛ ملفات المشروع والبيانات الأخرى لا تزال محتسبة.
- بعد إنشاء الكمبيوتر، ابقِ إعدادات سطح مكتب Oracle منفصلة؛ لا تشغّل `bootstrap.sh` على Codespaces؛ إنه مخصص لخادم Ubuntu مستقل لديك.

## تحقق بسيط من داخل الكمبيوتر

```bash
bash cloud-desktop-kit/codespaces-check.sh
```

هذه الأوامر للقراءة فقط؛ ليست هناك حاوية مخصصة ولا تنزيل تلقائي لحزم كبيرة. تظهر تفاصيل نظامك وموارده عند التنفيذ.

هذه أوامر تحقق؛ إنشاء Codespace والوصول إليه فعليًا لم يحدث داخل هذه المحادثة.

## خيار تجريبي: سطح مكتب رسومي حقيقي من Codespaces

بعد إنشاء Codespace، استخدم الأمر التالي **اختياريًا** إذا كانت حصة GitHub مجانية متاحة ومساحة القرص كافية:

```bash
bash cloud-desktop-kit/codespaces-desktop.sh
```

يشترط السكربت أن تعمل بالفعل داخل Codespaces؛ يتحقق من Docker وCompose ومساحة القرص (٦ جيجابايت على الأقل)، ويولد كلمة مرور محلية قبل تشغيل Webtop بدون Tailscale، ويستخدم المنفذ المحلي 3000 فقط. يرفض تبديل إعداد قائم مختلف. إذا لم يرد Webtop برمز `401` عند الدخول دون اعتماد، تُوقف الحاوية التجريبية ولا يُعلن النجاح. لتفتح الواجهة من هاتفك، انقر المنفذ `3000` في تبويب **PORTS** واحفظ الرؤية **Private** ولا تنشر المنفذ للعامة. لا تفعّل أي إنفاق مدفوع.

**قيود مهمة:** هذه تجربة قابلة للفشل وغير مثبتة على جلسة المستخدم. حجم Docker Webtop يُحسب ضمن استخدام التخزين والمساحة؛ الوقت ضمن الحصة. توقف Codespaces يوقف سطح المكتب، ولا تتحول الجلسة إلى خادم دائم. الوصول من الهاتف واكتمال الواجهة الرسومية يحتاجان اختبارًا ميدانيًا.

- مرجع المنافذ: https://docs.github.com/en/codespaces/developing-in-a-codespace/forwarding-ports-in-your-codespace
- مرجع Webtop: https://docs.linuxserver.io/images/docker-webtop/
