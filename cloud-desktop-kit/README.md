# حكيم — حزمة إعداد الكمبيوتر السحابي الخاص

**الإصدار:** ١٫١ — ١٣ تشرين الأول ٢٠٢٦

**الحالة:** حزمة إعداد وفحص، **غير منشورة وغير مختبرة على خادم Oracle حقيقي**.

## طريق أسرع قبل Oracle (من هاتفك)

راجع `CODESPACES.md` لفتح **كمبيوتر تطوير لينكس مؤقت** من المتصفح باستخدام الحساب المجاني المتصل بـGitHub؛ لا يحتاج حساب Oracle. هذا المسار ليس سطح مكتب XFCE دائمًا ولا هاتفًا أندرويد سحابيًا.

## ما الذي توفره؟

- سطح مكتب لينكس Ubuntu XFCE داخل حاوية Webtop متوافقة مع ARM64 / x86-64، عبر متصفح الهاتف.
- حفظ ملفات سطح المكتب في مجلد دائم على قرص الخادم، لا داخل الحاوية وحدها.
- اتصال عبر شبكة Tailscale الخاصة؛ خدمة سطح المكتب مربوطة فقط بالعنوان المحلي `127.0.0.1` ولا يُفتح منفذها للعامة.
- اسم مستخدم مستقل وكلمة مرور قوية تُنشأ محليًا عند التثبيت، وليست مرفقة بالحزمة.
- فحص مبدئي **للقراءة فقط** لإمكان تشغيل هاتف أندرويد عبر ReDroid، بلا تشغيل أو منفذ ADB.
- عزل تام عن مشاريع حكيم والمعلم الرقمي الحالية؛ لا مساس بخدمات Railway وRender الموجودة.

## ما الذي يلزم قبل الاستخدام؟

يلزم أولًا امتلاك آلة افتراضية **Ubuntu 24.04 ARM64**، ولديك حق الدخول إليها عبر SSH، بحجم لا يتجاوز حصة Oracle Always Free الفعلية لحسابك. توثيق Oracle يعرض حاليًا ٢ OCPU و١٢ جيجابايت RAM لخوادم A1 المجانية في الحسابات المجانية، والتوفر يعتمد على المنطقة. لا تختر آلة مدفوعة أو ترقِّ الحساب دون قرار منك. قد يلزم إنشاء حساب والتحقق ببطاقة، وهو إجراء شخصي لا يمكن للحزمة إنجازه نيابة عنك.

ستحتاج كذلك إلى حساب Tailscale مجاني، وربط هاتفك والخادم بالشبكة نفسها. تسجيل الدخول وموافقة الوصول لا يمكن أتمتتهما دون إذنك.

## الإعداد على خادم Ubuntu الجديد

انقل محتويات هذا الملف المضغوط إلى حسابك العادي على الخادم (لا تعمل بصلاحيات root مباشرة)، ثم شغّل:

```bash
chmod +x bootstrap.sh connect.sh status.sh android-readiness.sh
./bootstrap.sh
```

أثناء التشغيل يُطلب تأكيد `sudo` وربما تسجيل الدخول عبر رابط Tailscale. بعد اكتمال مصادقة Tailscale:

```bash
./connect.sh
./status.sh
```

افتح عنوان HTTPS الخاص الذي يظهر عند `tailscale serve status` من هاتف متصل بالشبكة نفسها. اسم مستخدم Webtop هو `hakim`، وكلمة المرور تُقرأ على الخادم باستخدام:

```bash
grep '^DESKTOP_PASSWORD=' ~/hakim-cloud-desktop/.env
```

**لا ترسل كلمة المرور إلى محادثة، ولا تنشرها أو تضعها في GitHub.** احمِ حساب Tailscale بالمصادقة الثنائية.

## فحص أندرويد السحابي

```bash
./android-readiness.sh
```

لا يعني نجاح المؤشرات الأولية إمكان تشغيل ReDroid فعليًا؛ إذ يحتاج إلى دعم وحدات Binder والذاكرة والمعمارية وصلاحيات حاويات خاصة. لا يثبّت هذا المشروع أندرويد ولا يفتح ADB على الإنترنت.

## اختبار ذاتي قبل التسليم

```bash
bash -n bootstrap.sh connect.sh status.sh android-readiness.sh
python3 -m unittest discover -s tests -v
```

الاختبارات ١١ (٦ لعزل الإعدادات و٥ لمحاكاة سلوك اتصال Tailscale). اختبار Python يتطلب مكتبة `PyYAML` لدى جهاز الفحص فقط، وليس على خادم الإنتاج. فحص Bash اختبارات تركيب لا يثبت نجاح تشغيل Docker على Oracle.

## المخاطر والحدود

- ليس ملكية دائمة للموارد؛ الاستضافة تخضع لشروط Oracle وحصة السعة واسترداد الموارد الخاملة.
- توليد كلمة مرور قوية لا يغني عن صلاحيات Tailscale ومراجعة وصول الأجهزة.
- فشل مصادقة Tailscale أو تعذر قراءة إعداد Serve السابق **يوقف الربط ولا يعد نجاحًا**؛ أُزيل ابتلاع أخطاء الربط في الإصدار ١٫١.
- لا تستخدم `Tailscale Funnel` أو تفتح منفذ 3000 أو 3001 أو 5555 للإنترنت.
- ملف `compose.yaml` يحدد صورة Webtop من مصدر خارجي. الإصدار ليس مثبتًا ببصمة، ولذلك يجب توثيق البصمة التي نجحت ميدانيًا قبل الترقية.
- البيئة المثبتة لا تتحول إلى هاتف بخط هاتف حقيقي، ولا تضمن خدمة Play Store أو العمل الصوتي أو GPU.
- الملفات والاعتمادات داخل الخادم مسؤولية مالكه، ويلزم نسخ احتياطي مشفر خارج الخادم. لا تتوقع نسخًا احتياطيًا تلقائيًا من هذه الحزمة.
