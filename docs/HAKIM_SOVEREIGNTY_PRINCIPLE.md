# مبدأ السيادة والاستقلال لحكيم

> لا مزوّد هو حكيم، ولا أداة هي حكيم، ولا اتصال خارجي هو حكيم. حكيم هو المقصد والعقد والحالة والمنهج والتحقق والتعافي. القرآن يحكم الغاية والقيم والحدود، والسنة الصحيحة بيان متثبت، والوسائل الدنيوية يحكمها الدليل والعقل والتجربة. كل خدمة خارجية قابلة للاستبدال، وكل نجاح يحتاج أثرًا مثبتًا، وكل صلاحية محكومة، وكل فشل له مسار تعافٍ، ولا يتوقف المقصد بفشل وسيلة.

## الحدود الحاكمة

- القرآن أصل الهداية والغاية والقيم والحدود الشرعية، والسنة الصحيحة بيان مع التثبت.
- لا يُنسب للوحي ما لم يثبت، ولا يُعامل الدين كآلية تقنية خفية.
- التقنية تُختار بالدليل العلمي والتجربة والقياس، وتبقى خاضعة للحق والعدل والأمانة وحفظ الحقوق والخصوصية ومنع الضرر.
- المستخدم صاحب المقصد والقرار والحدود؛ الأتمتة تعمل بأقل صلاحية لازمة، ولا توسع أثرها أو كلفتها أو بياناتها دون تفويض.
- النجاح التقني لا يساوي الأثر الميداني؛ لا يُعلن الإغلاق قبل الدليل.

## قواعد الاستقلال

1. لا مزود منفرد نقطة فشل مركزية.
2. الوظائف الأساسية محلية أولًا ما أمكن.
3. القنوات الخارجية وسائل قابلة للاستبدال، وليست مصدر هوية أو سلطة.
4. البيانات الحاكمة والسجلات قابلة للتصدير والاستعادة، والأسرار لا تدخل السجل العام.
5. عند فشل النقل: مسار بديل آمن؛ وعند فشل الشبكة: حفظ محلي مشفر ثم إعادة إرسال.
6. لا يُخفض مستوى التشفير أو الخصوصية لمجرد تعطل المزود.
7. أي عمل مغير للحالة يبقى خلف بوابة الموافقة المناسبة.
8. آخر نجاح مثبت يُحمى من التغييرات غير المثبتة.

## بروتوكول النتائج السيادي

طبقة `HakimSovereignResultChannel` تضيف تدرجًا محافظًا على التوافق:

- المسار الأول: قناة النتائج الآمنة الحالية.
- المسار الثاني: ناقل مباشر مشفر `HR1` باستخدام AES-256-GCM ومفتاح HC1، دون إرسال النتيجة الحساسة كنص مكشوف.
- المسار الثالث: صندوق نتائج محلي مشفر بمفتاح AndroidKeyStore.
- عند عودة الاتصال: حارس التعافي يعيد تفريغ الصندوق تلقائيًا.

لا تخزن طبقة الصندوق مفاتيح الاقتران داخله، ولا تنشئ Webhook موازيًا، ولا تغير هوية الحزمة أو التوقيع أو بيانات المستخدم.

## قاعدة الإثبات

حالة المصدر أو CI لا تثبت الهاتف. مرشح السيادة يبقى `NOT_PROVEN_FIELD` حتى يثبت على الجهاز نفسه:

`أمر مشفر → حكيم → تنفيذ مأذون → نتيجة → مسار بديل عند فشل المزود → استرداد الصندوق → أثر مرئي`.

## سيادة التفكير والحتمية — خط ٢٠٠٤٥

الهدف ليس ادعاء استقلال مطلق عن المادة أو نظام التشغيل؛ بل إزالة الارتهان لأي مزود رقمي منفرد مع بقاء الاعتماد الواقعي على الهاتف وAndroid والطاقة معلنًا.

طبقات السيادة المطلوبة:
- الحاكمية والسلطة والحدود محلية وثابتة ولا يملك النموذج تعديلها.
- اختيار الأدوات والمسارات والتعافي حتمي وقابل للتدقيق، مع آخر خط أساس مثبت.
- المهمة والحالة والأدلة والتعلم تحفظ محليًا ويمكن استعادتها.
- الاستدلال المتقدم المحلي مسار أصيل عبر loopback فقط، بلا API key وبلا نقل بيانات خارج الهاتف.
- المزودات الخارجية احتياط اختياري قابل للاستبدال ولا تصبح هوية حكيم أو مصدر سلطته.
- عندما لا يوجد نموذج محلي متقدم، يستمر القلب الحتمي المحلي فيما يستطيع إثباته ولا يدعي تكافؤ نموذج غير موجود.
- خرج أي نموذج لغوي احتمالي بطبيعته؛ لذلك الحتمية تطبق على الحاكمية والاختيار والبوابات والتحقق، لا على احتمال كل كلمة يولدها النموذج.
- لا تعتبر جاهزية الاستدلال المحلي مثبتة لمجرد وجود منفذ؛ يلزم اكتشاف بروتوكول محلي صالح وهوية نموذج فعلية، ثم اختبار ميداني على الهاتف.

### معيار الإغلاق

لا يعلن استقلال التفكير الميداني حتى يثبت على الهاتف نفسه:
`شبكة خارجية مقطوعة → نموذج محلي جاهز → مهمة استدلال متقدمة → تنفيذ مأذون → تحقق من الأثر → حفظ واستعادة بعد إعادة التشغيل`.

ولا يعلن الاستقلال الشامل حتى ينجح أيضًا تعافي النتائج المحلي، استعادة الحالة، سلامة التوقيع، والنسخ/الاستعادة دون خدمة خارجية إلزامية.

## Runtime الاستدلال المحلي للهاتف

مرشح ٢٠٠٤٥ يكتشف واجهة OpenAI-compatible على loopback فقط. ولإنشاء runtime فعلي على Android/Termux يوجد:
`scripts/hakim-local-model-termux.sh`.

العقد:
- llama.cpp مثبت على `v0.4.1 / b29c606`.
- النموذج المرجعي: `ggml-org/Qwen3-1.7B-GGUF`، كمية `Q4_K_M`.
- بصمة النموذج المتوقعة: `d2387ca2dbfee2ffabce7120d3770dadca0b293052bc2f0e138fdc940d9bc7b5`.
- الخادم ملزم بـ `127.0.0.1` ولا يفتح `0.0.0.0`.
- readiness لا يثبت بمجرد فتح منفذ؛ يجب أن يعيد `/v1/models` هوية النموذج.
- تنزيل النموذج (~١٫٢٨ جيجابايت) لا يحدث افتراضيًا؛ يلزم `HAKIM_ALLOW_MODEL_DOWNLOAD=YES`.
- بعد التحقق يبدأ `llama-server` على المنفذ ٨٠٨٠ ويجري smoke test عبر `/v1/chat/completions`.
- لا API key ولا حساب سحابي مطلوبان للمسار المحلي.

لا يثبت وجود هذا السكربت أن الهاتف مؤهل ميدانيًا. التأهيل يتطلب تشغيله على الجهاز الحقيقي، ثم اختبار وضع الطيران، استدلال عربي فعلي، تعافي بعد قتل العملية/إعادة التشغيل، وملاحظة عدم وجود اتصال خارجي أثناء المهمة.
