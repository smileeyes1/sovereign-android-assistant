# HAKIM PRODUCT V1 — THREAT MODEL

الأصول: هوية التطبيق D1، أسرار المزودين، ملفات المستخدم، الجلسات، قناة التحكم، سجل المحادثة.

التهديدات الأساسية:
- تطبيق مزور أو تحديث بهوية مختلفة.
- تسريب أسرار عبر Logs/واجهة/مستودع.
- أمر بعيد قديم أو مزور أو مكرر.
- WebView خبيث يطلب كاميرا/ميكروفون/موقع بلا حاجة.
- تنفيذ خارجي يُعرض كنجاح رغم عدم تحقق الأثر.
- فقدان الشبكة أو موت الخدمة أثناء مهمة.
- ملف/موقع يحاول تحويل بياناته إلى أوامر.

الضوابط:
- D1 trust anchor + signer gate.
- HMAC/عمر الأمر/منع التكرار.
- HTTPS وmixed-content disabled.
- صلاحيات حساسة عند الطلب فقط.
- فصل بيانات المواقع والمرفقات عن سلطة التعليمات.
- fail-closed عند غياب الدليل.
- rollback forward من خط أساس مثبت.
