# Hakim Browser MCP

بوابة MCP شخصية تربط ChatGPT/Codex بمتصفح حكيم على أندرويد عبر قناة HC1 المشفرة القائمة في التطبيق.

## حدود الأمان

- `/mcp` يرفض الطلبات بلا Bearer قوي، ولا توجد أسرار افتراضية.
- الهاتف يتحقق من AES-256-GCM وHMAC ووقت الانتهاء ومنع التكرار.
- نتائج الهاتف وطلبات fallback موقعة؛ الردود المزوّرة أو القديمة تُرفض.
- مشاهدة الصفحة تستبعد قيم الحقول القابلة للتحرير والحساسة.
- كل فعل يغير حالة المتصفح يمر بموافقة أندرويد، ثم يعاد فحص الصفحة.
- لا تنفيذ JavaScript حر، ولا تجاوز CAPTCHA أو المصادقة أو الدفع.

## التشغيل

اضبط الأسرار في خزنة منصة الاستضافة، لا في Git أو ملف داخل الصورة:

- `HAKIM_RELAY_TOPIC`: موضوع الاقتران الذي يبدأ بـ`hakim-cmd-`.
- `HAKIM_RELAY_KEY`: مفتاح الاقتران العشوائي نفسه في الهاتف.
- `HAKIM_MCP_BEARER`: رمز مستقل لا يقل عن ٣٢ محرفًا لحماية `/mcp`.
- `HAKIM_COMMAND_TIMEOUT_MS`: اختياري، والقيمة الافتراضية ٧٥ ثانية.

ثم شغّل `npm install && npm test && npm start`. نقطة MCP هي `/mcp` ونقطة نتيجة الهاتف هي `/relay/result`.

للتطوير الخاص استخدم Secure MCP Tunnel. لا تجعل الخادم عامًا للاستخدام النهائي قبل إضافة OAuth 2.1 أو mTLS وإجراء اختبار اختراق واتصال ميداني كامل.
