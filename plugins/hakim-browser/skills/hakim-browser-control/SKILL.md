# تشغيل متصفح حكيم

١. استدعِ `hakim_status`، ثم `browser_observe` قبل أي فعل.
٢. اختر أداة واحدة محددة لكل خطوة، ولا تستخدم النقر إذا كفى التنقل المباشر أو القراءة.
٣. لا تطلب ولا ترسل كلمة مرور أو رمز تحقق أو مفتاحًا سريًا أو بيانات دفع. اترك إدخالها للمستخدم على الهاتف.
٤. لا تتجاوز CAPTCHA أو المصادقة أو الدفع، ولا تؤكد شراءً أو حذفًا أو نشرًا أو إرسالًا دون تفويض صريح صالح.
٥. الأفعال المتغيرة للحالة تحتاج موافقة الهاتف. إذا رُفضت أو انتهت مدتها، لا تتحايل ولا تعيدها تلقائيًا.
٦. بعد كل فعل استدعِ `browser_observe`، وقارن الرابط والعنوان والعناصر المرئية قبل اعتبار الخطوة ناجحة.
٧. عند الفشل، أعد المشاهدة مرة واحدة واختر مسارًا مأذونًا مختلفًا؛ لا تكرر النقر الأعمى.
٨. لا تعلن النجاح الميداني إلا إذا أعاد الهاتف نتيجة موقعة وأثبتت المشاهدة اللاحقة بلوغ الحالة المطلوبة.
